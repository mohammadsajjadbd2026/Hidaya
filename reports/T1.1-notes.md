# T1.1 — notes on how the source inventory was collected (14-11-2026)

## How the Shamela cards were read
- `shamela_get_book` and `shamela_get_book_parts` gave the flags, authors, type, parts and page counts.
- `shamela_search_books` returns only a window of about 170 characters of the bibliography card. The window sits around the **earliest** token of the query that matches the card. To read past it, I queried tokens that appear later in the card (for example مصفى، يليه مفصولا، شعبان، بيروت الإسلامية، القبلة). Each `evidence` field holds the snippets copied verbatim and joined.
- The search uses AND. A query of `<a card-specific token> + ترقيم / للمطبوع / آليا / غير` therefore shows whether the card contains each token.
  - Verbatim «[ترقيم الكتاب موافق للمطبوع]» was seen for S2, S5, S7, S8, S9 and S10.
  - For S1, S4, S6, S11, S12, S13 and S14, `matches_print` = "yes" is **inferred** from the token tests (ترقيم + للمطبوع present, آليا absent). Each of these records says so in `unverified_reason`.
- Scoped searches (author_ids, category_ids, period_*, downloaded_only) gave unreliable or empty results. Do not rely on them.
- Digits are not indexed, so a year or a volume count cannot be searched for.
- The card for S3 (811) is on page 1 of the book. S15 (132617) is not in the search index at all. Its title page (page 1) is the only source.
